Aneurysm Subtype Classifier

TAV-ATAA vs BAV-ATAA — Logistic Regression trained on 30 organelle morphology features (LOPO-CV bal. acc. = 0.93)

How it works: This classifier uses the segmentation masks already loaded in the Segmentation tab. It extracts all 30 morphological features (Nucleus, Actin, Mitochondria) from the current cell and predicts whether the cell morphology is more consistent with TAV-ATAA (tricuspid aortic valve aneurysm) or BAV-ATAA (bicuspid aortic valve aneurysm).

Prerequisite: Load an OIR file and run segmentation in the Segmentation tab first.
