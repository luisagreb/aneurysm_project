Abstract
We present an automated computational pipeline to detect morphological changes in aortic endothelial cells associated with Thoracic Aortic Aneurysm (TAA). Using confocal microscopy of three sub-cellular organelles — nucleus, actin, and mitochondria — we trained nnU-Net segmentation models and extracted 29 morphological features per cell. Statistical analysis and machine learning classifiers were applied to distinguish healthy from diseased cells and to assess the effect of collagen treatment.
Inquiry
Can 3D sub-cellular morphology alone distinguish healthy from TAA endothelial cells, and does collagen treatment restore a healthy morphological phenotype?
Background & Dataset
Thoracic aortic aneurysm involves progressive deterioration of the aortic wall. Endothelial cells undergo structural remodelling detectable at the sub-cellular level. We imaged 178 manually annotated cells from four experimental groups using confocal microscopy at 60× magnification:

Three-channel Z-stacks (nucleus · actin · mitochondria) were converted to NIfTI format and manually segmented to train independent nnU-Net models.

Methods: Feature Extraction
Binary masks were processed with morphological closing (3×3×3 ball) before feature extraction using analyze_structures.py. All measurements were converted to physical units (µm) using per-cell voxel spacing from NRRD metadata.

Results: Statistical Analysis
📊
Kruskal-Wallis + Dunn's test (Bonferroni): significant morphological differences across the 4 experimental groups in actin skeleton length, mitochondrial fragmentation, and nuclear elongation.
📈
Linear Mixed Models (BH-FDR corrected): Disease × Collagen interaction significant for multiple actin and mitochondrial features, suggesting collagen partially rescues the TAA morphological phenotype.
🔬
Subject identity included as a random effect to account for within-subject cell-level correlations.

Conclusion
  • nnU-Net accurately segmented all three organelles (Dice 80–91%) from 3D confocal microscopy volumes with no manual parameter tuning.
  • 29 morphological features captured structural remodelling signatures of TAA endothelial cells.
  • Random Forest classifiers distinguished Healthy from TAA cells with >80% accuracy using sub-cellular morphology alone.
  • Collagen treatment induced measurable morphological changes detectable by ML classification, suggesting partial phenotypic rescue.
