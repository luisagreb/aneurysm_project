OVERVIEW
--------
This script creates binary masks from NRRD channel files using thresholding and
morphological operations. It processes multiple folders and creates masks for
channels 0, 1, and 2, with special enhanced cleanup for channel 1 (actin).


MAIN FEATURES
-------------
1. Fixed and Dynamic Thresholding Support
   - Fixed integer thresholds (simple and fast)
   - Dynamic methods: Otsu, percentile, mean+std (adaptive per image)

2. Channel-Specific Processing
   - Channel 0: Standard processing
   - Channel 1 (Actin): Enhanced cleanup to remove side dots while preserving strands
   - Channel 2: Standard processing

3. Morphological Cleanup
   - Binary opening: Removes small noise/dots
   - Binary closing: Fills holes and connects nearby structures
   - Small object removal: Filters out components below size threshold
   - Distance-based filtering: Removes objects far from main structure (channel 1 only)

  2. Sauvola k still too high - threshold too aggressive for dim regions
  3. Need to thicken lines, not just preserve them
Changes:
  1. Frangi sigma range: (1,3) → (1,7) - detects thicker/out-of-focus filaments
     - Broader range captures more continuous structures, not just edges
  2. Sauvola k parameter: 0.05 → 0.01 (VERY sensitive)

  3. Sauvola window_size: 25 → 51 (better background estimation)
     - Larger window prevents over-segmentation of filaments
  4. Morphological: Added dilation BEFORE closing
     - Dilation thickens the filaments slightly
     - Closing then fills gaps and connects nearby strands

Result: Continuous, solid filaments instead of dashed outlines

================================================================================
TECHNICAL DETAILS
================================================================================

Morphological Operations:
-------------------------
1. Binary Opening (erosion followed by dilation):
   - Removes small noise and isolated dots
   - Structure size determines how much is removed
   - Larger structure = more aggressive removal

2. Binary Closing (dilation followed by erosion):
   - Fills small holes and gaps
   - Connects nearby structures
   - Helps preserve continuous actin strands

3. Connected Component Labeling:
   - Identifies separate objects in the mask
   - Allows filtering by size and distance

4. Distance-Based Filtering (Channel 1 only):
   - Finds largest component (main actin structure)
   - Calculates centroid of main structure
   - Removes components far from main structure
   - Preserves nearby strands and extensions


Threshold Selection Guide:
--------------------------
Lower threshold (e.g., 200-250):
  - Captures more dim actin strands
  - May include more noise
  - Better for thin/fine structures

Higher threshold (e.g., 300-350):
  - Captures only bright structures
  - Less noise
  - May miss dim strands

Current setting (250):
  - Balanced approach
  - Captures most actin while controlling noise
  - Works well with enhanced cleanup


Cleanup Parameter Tuning:
-------------------------
If masks have too much noise:
  - Increase threshold (250 → 280-300)
  - Increase opening structure (3x3x3 → 4x4x4)
  - Increase min_size multiplier (2x → 3x)
  - Decrease distance threshold (40% → 30%)

If masks miss actin strands:
  - Decrease threshold (250 → 220-240)
  - Decrease opening structure (3x3x3 → 2x2x2)
  - Decrease min_size multiplier (2x → 1.5x)
  - Increase distance threshold (40% → 50%)
